핏챠

헬스장 운영, 앱 하나로 끝.

회원·수업·매출·정산을 한 곳에서.
헬스장 대표와 트레이너가 함께 쓰는 관리 앱입니다.

곧 App Store에서 만나요

●헬스장 업무가 앱에서 돌아갑니다

회원 등록, 수업 일정, 상담 기록, 업무 부여까지. 매일 하던 일이 앱 하나로 정리됩니다.

●정산은 앱이 계산합니다

트레이너별 완료 수업 기준으로 자동 집계됩니다. 월말에 엑셀 붙잡고 싸울 일이 없습니다.

●우리 센터가 숫자로 보입니다

매출·회원 현황·연령·운동 목적까지 한눈에. 대표와 트레이너가 같은 데이터를 봅니다.

감으로 하던 운영, 데이터로 바꿉니다

회원마다 기록이 쌓입니다

목표 달성률, 인바디 측정, 회원별 사진이 날짜별로 데이터화됩니다. “기간 슬슬 끝나가시는데…”가 아니라, 수업 중 쌓인 기록으로 재등록을 설득합니다.

운동일지를 카드로 공유합니다

사진과 텍스트를 보기 좋은 카드로 만들어 회원님께 바로 전송합니다. 회원은 자기 변화를 눈으로 보고, 재등록할 이유를 스스로 찾습니다.

어떤 회원이 오는지 보입니다

신규 유입·재등록이 어떤 연령, 어떤 목적, 어떤 성별에서 나오는지 숫자로 확인합니다.

트레이너별 성과가 보입니다

누구에게 신규가 붙고 누구에게 재등록이 잘되는지 월별 실적으로 비교됩니다. 재등록이 잘 되는 층과 안 되는 층, 상담이 어디서 끊기는지도 전환율로 보입니다.

업무가 루틴이 됩니다

반복 업무를 루틴으로 묶어 매번 같은 기준으로 점검합니다. 업무 부여와 진행 상황이 기록돼, 누가 뭘 하는지 묻지 않아도 보입니다.

이런 것까지 됩니다

대표용

  • 회원 관리—등록·조회·담당 트레이너 지정, 연령·성별·운동 목적별 분포
  • 상담 관리—상담 기록·결과·미전환 사유까지 회원과 연결해 보관
  • 결제·매출—결제 내역과 매출 분석을 화면에서 확인
  • 재등록 관리—재등록 회원 표시, 재등록률·기준별 분석
  • 담당 인계—트레이너 간 회원 인계, 이력 기록
  • 정산 관리—월별 완료 수업 기준 트레이너 정산 자동 집계
  • 업무 관리—업무 부여(마감일·지시 사진), 진행 전/완료 확인, 업무 보고
  • 트레이너 평가—월별 신규·재등록 실적 확인

트레이너용

  • 내 회원—담당 회원 목록, 목표·인바디·사진 기록
  • 운동일지—수업 기록 작성, 카드로 회원에게 공유
  • 수업 관리—수업 일정·완료 처리
  • 내 강·약점—재등록 잘 되는 층/안 되는 층 확인
  • 내 정산—기간별 완료 수업 기준 정산 금액 확인
  • 알림 설정—수신 여부를 앱에서 직접 설정
